# 💱 Currency Convertor

A simple and clean frontend web application built with **React** and **Tailwind CSS** to convert currencies using real-time exchange rates from a public API.

## 🛠️ Tech Stack

- React (with Vite)
- Tailwind CSS
- JavaScript (ES6+)
- Currency Exchange API

## ✨ Features

- Convert between any two global currencies
- Real-time exchange rate updates via external API
- Responsive and minimalist UI with Tailwind
- Error handling for empty/invalid inputs
